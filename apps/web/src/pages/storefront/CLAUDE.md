# `pages/storefront`

The shop's front page at `/`: the mockup's upper half — header, banner, service tiles, Steam top-up, one product row — as page-local sections with every Russian string in `config/`; the five graded interactions live here, and the row hands «Купить» to `features/buy-product`.

- **One `document` click listener for the catalog menu, none on the Каталог button** — `ui/catalog-menu.ts` registers it, and it classifies every click on the page exactly once (on the button / inside the overlay / outside) and hands that class to `reduceMenu` in `model/menu.ts`; the reducer decides, the binding paints `hidden` and `aria-expanded`. A second `document` click listener for the menu, or one on the button, reintroduces the bubbling-order bug R3 describes — the opening click bubbling up to be read again as an outside click — and the usual patch, `stopPropagation`, would also hide the click from `enableBuyControls`'s delegated listener on the product row. Checks: `grep -n 'addEventListener("click"' ui/catalog-menu.ts` returns one line, on `document`; `grep -rn '\.stopPropagation(\|\.preventDefault(' --include='*.ts'` over this directory returns nothing. "Inner clicks are inert" is markup, not a handler: categories are `<button type="button">` with no listener, items are `<li>` text, and `grep -rn 'createElement("a"' --include='*.ts'` over this directory returns nothing (Slice 3).
- **One timer slot for the carousel, and one `setTimeout` on the page** — the call is in `model/countdown.ts` and nowhere else (`grep -rn "setTimeout(" --include='*.ts'` over this directory returns that one line). `model/carousel.ts` emits exactly one timer instruction per event (`restart` / `cancel` / `keep`); `ui/banner.ts` turns it into a call in one function, `applyTimer`; and `restart` always clears before it sets, so there is never more than one pending timeout. Anything that later wants a timer here — a second carousel, a delayed hover, a toast — routes through that reducer and that countdown rather than calling `setTimeout` itself. `pagehide` cancels the countdown; a persisted `pageshow` restarts it through the reducer (Slice 2).
